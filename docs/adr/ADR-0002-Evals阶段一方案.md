# ADR-0002：Evals 阶段一方案（规则断言先行）

- 日期：2026-09-15
- 状态：已接受（细节待 ADR-0003：指标定义与运行策略）
- 会话：grill-with-docs

## 背景

Evals 最大的坑是“测了个寂寞”：SSH 与 LLM 全 mock 后，测的只是自己的 mock。
反过来全量真调主力模型：贵、慢、flaky，CI 跑不起。

## 决策

1. **判法：规则断言先行，LLM 裁判放阶段二**
   - 规则保证下限（SOP 顺序、审批触发、参数合法性全是确定性的），便宜稳定
   - 裁判自己会幻觉，不能作为唯一判据；只负责规则写不出的东西（如错误解释是否如实）
2. **被测模型：真调小模型跑全量**，nightly 再抽样跑主力模型
3. **数据集：都要**——手工 golden 集做 PR 门禁，生产日志（audit_log + deployments）回放做回归池

## 后果

- 阶段一交付物：确定性断言集 + 小模型全量报告 + 门禁集成
- 阶段二再引入 LLM-as-judge（抽样 + nightly）
- 待定（下一轮访谈）：5 个核心指标定义、CI/nightly 运行策略、harness 落点
