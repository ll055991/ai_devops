# ADR-0004：M2 LLM 成本可观测

- 日期：2026-09-15
- 状态：已接受（实施细节待定）
- 会话：grill-with-docs

## 决策

1. **另起 `llm_usage` 表**，按 thread × 轮次记明细
   - 否决 audit 加字段：interrupt/resume 重放消息会导致重复记账
   - 否决只记总量：丢明细，看不见哪个环节最烧 token
2. **只记 tokens，不换算钱**：input/output/total tokens 落库，费率表以后再说
3. **数据源**：`AIMessage.usage_metadata`（after_model 钩子里直接可拿）
4. **写入点**：`DeployApprovalMiddleware.after_model` 顺手记（thread_id 链路已修好），写失败不阻断主流程
5. **M2 完成标准**：任意 thread 的 token 明细可查（轮次 × 模型 × 用量）

## 后果

- 模型路由、小模型替换等优化动作是 M3+ 的事：先有账本，再谈省钱（呼应 ADR-0001 先基线后优化）
