# ADR-0001：后续优化路线总体目标

- 日期：2026-09-15
- 状态：已接受
- 会话：grill-with-docs（简历导向优化路线访谈）

## 背景

项目本体（Agent 驱动部署系统）功能闭环已通：20 个工具、5 中间件、审批、审计、状态跟踪、单页工作台。
后续优化的目标是**写进简历有含金量**，目标岗位：AI 应用 / 大模型工程，时间：长期打磨。

## 决策

简历评审看四个支柱，按此排优化优先级：

1. **Evals（评估体系）**—— agent 质量的量化证明，AI 岗最硬通货
2. **可靠性**—— guardrails、故障恢复、幂等、检查点正确性
3. **成本**—— token 可观测、分摊统计、模型路由
4. **自主性**—— 从执行 SOP 到故障自愈、自主运维

里程碑 1 只做 Evals（见 ADR-0002）。贪多是简历杀手：一个讲透的故事 > 四个半吊子功能。

## 后果

- 不再以“加功能”衡量进度，以“可量化的质量证据”衡量
- 每个后续优化必须回答：指标是什么、基线多少、优化后多少
